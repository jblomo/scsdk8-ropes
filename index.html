Player 1 (WASD)

Length: 3

Stored item: None

Score (berries eaten): 0

Player 2 (Arrow Keys)

Length: 3

Stored item: None

Score (berries eaten): 0

Item Rules

Berries grow your snake by 2 segments and increase score.

Laser removes up to 4 tail segments from the other player.

Trap places a trap tile. If the other player hits it, they lose 3 tail segments.

Use Items

Player 1: press F to use stored item.

Player 2: press / to use stored item.

Restart game: press R.
